# Support

For installation questions, read [the guide](docs/installation.md) and [troubleshooting](docs/troubleshooting.md), then use the [setup-help form](https://github.com/Forza-WCCF/FOOTISTA-2019/issues/new?template=setup_help.yml).

For a repeatable client problem, use the [bug-report form](https://github.com/Forza-WCCF/FOOTISTA-2019/issues/new?template=bug_report.yml). Include the client version, Windows version, what you did and what happened. A cropped screenshot and the exact error text are more useful than a whole installation dump.

GitHub issues are public. Never attach approval codes, passwords, tokens, DPAPI credential files, private signing keys, Aime/account maps, browser profiles or player databases. Review logs before posting them and share only the relevant excerpt.

For private account matters, use the contact options available while signed in to [wccf.online](https://wccf.online); do not post account secrets in a GitHub issue.

Game files are external to this project. Client issue reports should describe the selected game version and archive layout, without attaching the game archive.
